# core-new-functionalities

Propuestas de funcionalidades nuevas para el core del backend, generadas por el agente `@core-new-functionalities-planner` (`.claude/agents/core-new-functionalities-planner.md`).

- **Nombre de archivo:** `<funcionalidad-name>-<id>.md` — nombre en kebab-case sin acentos e id de tres dígitos correlativo (`001`, `002`, …).
- **No son specs.** Son insumo para `/spec`: si una propuesta se aprueba, se diseña como `specs/NN-nombre.md`.
- **Status:** nace como `Propuesta`; una persona lo cambia a `Aprobada`, `Descartada` (con motivo) o `Convertida en spec NN`. El agente nunca sobrescribe ni edita una propuesta existente, y no vuelve a proponer una idea `Descartada`.
- Las funciones del chatbot IA (spec 28) no van aquí: esas las propone `@chat-ai-function-calling-planner` en `specs/chat-ai-planner/`.
